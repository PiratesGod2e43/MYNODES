# PiratesNodes Modrinth Installer
Includes:
- Modrinth search
- Mods / Plugins tabs
- Minecraft version filter
- Fabric / Forge / NeoForge / Paper / Purpur selection
- Compatible version lookup
- Primary download-file selection
- Docker deployment

Run:
npm install
npm run dev

The UI safely resolves a compatible Modrinth file. Actual installation into a running Minecraft server requires a secure node-agent with server-specific authorization and filesystem access.
